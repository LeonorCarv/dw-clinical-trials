# Data

## extract/
Project subset of the AACT database (snapshot 2026-11-22), exported from the
`staging` schema as compressed CSV files (UTF-8, comma-separated, with header).

Scope: interventional trials started between 2012 and 2024 in four therapeutic
areas (oncology, neurology, cardiovascular, infectious diseases).

| File | Content |
|---|---|
| scope_trials | Trials in scope (one row per trial) |
| scope_trial_area | Therapeutic area(s) of each trial |
| trials | Core attributes, key dates and calculated indicators |
| designs | Study design (allocation, model, purpose, masking) |
| eligibilities | Eligible sex and age groups |
| sponsors | Lead sponsor and collaborators |
| interventions | Intervention type and name |
| conditions | Conditions mapped to MeSH terms |
| mesh_tree | MeSH tree numbers (condition hierarchy) |
| countries | Countries where each trial takes place |
| site_counts | Number of sites per trial and country |
| adverse_events | Adverse events by result group, event type and organ system |
| result_groups | Result groups (arms) referenced by the adverse events |

Generated by `sql/01_staging/02_extract_subset.sql` and `etl/export_extract.py`.

## raw/
Not versioned. Place the AACT dump here or anywhere outside the repository.
